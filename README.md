静态库是在编译时可完整复制到最终可执行文件中的库
动态库是在运行时被加载到内存中的库，可以被多个程序共享
静态库中的代码需要重新编译，动态库中的代码是编译好的
环境变量是现代软件开发和系统管理中的重要工具，它有系统环境变量和用户环境变量
